BAM 9月期 テキスト修正一覧
（明らかな誤字・変換ミスのみ。原文はLINEトーク書き出しを参照）

■ day0
  僕が222奥円の売上を作れた
    → 僕が222億円の売上を作れた    （億→奥の変換ミス）
■ day1
  何事も飛び込ぶ前は、
    → 何事も飛び込む前は、    （飛び込む の誤字）
■ day2
  学ぶのをめんどくさる
    → 学ぶのをめんどくさがる    （「が」の脱字）
  絶対に一緒に居ない用にしましょう
    → 絶対に一緒に居ないようにしましょう    （よう→用 の変換ミス）
  バトミントン
    → バドミントン    （バドミントンの誤記）
■ day3
  エネルギ－値
    → エネルギー値    （長音符が全角ハイフンになっている）
  大橋社長のが乗ってました
    → 大橋社長のが載ってました    （載る→乗る の変換ミス）
■ day4
  それを紐つけましょう
    → それを紐づけましょう    （濁点の脱落）
■ day5
  『助けを借りれらたり』
    → 『助けを借りられたり』    （れら→られ の入れ替わり）
  大失敗した方も何名がいます
    → 大失敗した方も何名かいます    （か→が の打ち間違い）
  そんなサイくルから
    → そんなサイクルから    （くル→クル の変換ミス）
  自分毎に置き換えて
    → 自分事に置き換えて    （自分事 の変換ミス）
■ day6
  聞いてくれるケーズが多いです
    → 聞いてくれるケースが多いです    （ケーズ→ケース）
■ day7
  『お店の定員さん』
    → 『お店の店員さん』    （定員→店員 の変換ミス）
  広報の方繋から、
    → 広報の方繋ぐから、    （「ぐ」の脱字）
  ラポールしっかり気付いて
    → ラポールしっかり築いて    （気付く→築く の変換ミス）
  ドンキーホーテ
    → ドンキホーテ    （店名の誤記）
  くらいグタグタ続く
    → くらいグダグダ続く    （グタグタ→グダグダ）
  出来上がるたんだけど
    → 出来上がるんだけど    （余分な「た」）
  足はどちらかと言ったら甘さ控えめ
    → 味はどちらかと言ったら甘さ控えめ    （足→味 の変換ミス）
  イベントあるだるんだけど
    → イベントあるんだけど    （余分な「だる」）
  ワンポイントアドパイス
    → ワンポイントアドバイス    （パ→バ）
  必ず送りください
    → 必ず送ってください    （「って」の脱字）
  何度で何度でも
    → 何度でも何度でも    （「も」の脱字）
  アプローチにが上手くなる
    → アプローチが上手くなる    （助詞の重複）
  『伝えた数✖︎スピード顔』
    → 『伝えた数✖︎スピード』    （余分な「顔」）
■ day8
  下記のURLからと飛べます
    → 下記のURLからも飛べます    （と→も）
  またむづかしかった
    → またむずかしかった    （現代仮名遣いでは「むずかしい」）
  当日のbさんの動きが
    → 当日のBさんの動きが    （他は全て大文字のBさん）
  bさんの大切な動きを
    → Bさんの大切な動きを    （他は全て大文字のBさん）
■ day9
  勿体無い行動をしていしまう
    → 勿体無い行動をしてしまう    （余分な「い」）
